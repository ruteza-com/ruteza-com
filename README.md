## Полезные инструменты начинаются с реальной задачи

Мы — **Рутеза**. Разрабатываем программные решения, которые помогают бизнесу автоматизировать повседневную работу, связывать сервисы и применять искусственный интеллект на практике.

Здесь публикуем открытый код и делимся подходами, которые можно изучать, применять и развивать вместе с нами.

### Направления

**Автоматизация бизнеса**  
Инструменты для повторяющихся операций, обработки данных и рабочих процессов.

**ИИ и интеграции**  
Связь сервисов, работа с API и применение моделей к прикладным задачам.

**Маркетплейсы**  
Решения для работы с данными площадок и автоматизации задач продавцов.

### Наш открытый код

Публикуем решения по мере готовности к открытому использованию. Возможности, установка, примеры и условия лицензии описываются в каждом репозитории отдельно.

### Развиваем вместе

Нашли ошибку или придумали улучшение — откройте **Issue** в нужном проекте. Хотите предложить изменение кода — создайте **Pull Request**, предварительно прочитав правила участия этого репозитория.

Для вопросов по конкретному решению лучше использовать его Issues: так ответ смогут найти и другие участники.
